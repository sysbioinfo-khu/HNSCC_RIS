# HNSCC_RIS

### Description
Analysis scripts for "Radiotherapy-induced senescent cells orchestrate a pro-metastatic niche and drive radio-resistance in head and neck cancer".

Table of contents :
- Fig1: scripts for WGCNA analysis
- Fig2: scripts for characterizing radiotherapy-induced senescence (RIS) cells in scRNA-seq data
- Fig3: scripts for clonal analysis
- Fig4: scripts for regulatory analysis in RIS population
- Fig5: scripts for paracrine effects in malignant and endothelial cells within the senescent niche
- Fig6: scripts for paracrine effects in fibroblast cells within the senescent niche

### Processed data
Processed data generated from these scripts are available on Zenodo, https://doi.org/10.5281/zenodo.22740567
