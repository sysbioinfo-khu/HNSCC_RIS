# HNSCC_RIS

### Description
Analysis scripts for "Radiotherapy-induced senescent cells orchestrate a pro-metastatic niche and drive radio-resistance in head and neck cancer".

Table of contents :
- Fig1: scripts for WGCNA analysis
- Fig2: scripts for characterizing radiotherapy-induced senescence(RIS) cells in scRNA-seq data
- Fig3: scripts for clonal analysis
- Fig4: scripts for regulatory analysis in RIS populuation
- Fig5: scripts for paracrine effect in malignant, endothelial cells of RIS population in senescent niche
- Fig6: scripts for paracrine effect in fibroblast cells

### Processed data
Processed data from scripts are provided in Zenodo, https://doi.org/10.5281/zenodo.22740567
