# HNSCC_RIS

### Description
Analysis scripts for "Radiotherapy-induced senescent cells orchestrate a pro-metastatic niche and drive radio-resistance in head and neck cancer". \t

Table of contents : \t
  Fig1: scripts for WGCNA analysis\t
  Fig2: scripts for characterizing radiotherapy-induced senescence(RIS) cells in scRNA-seq data\t
  Fig3: scripts for clonal analysis\t
  Fig4: scripts for regulatory analysis in RIS populuation\t
  Fig5: scripts for paracrine effect in malignant, endothelial cells of RIS population in senescent niche\t
  Fig6: scripts for paracrine effect in fibroblast cells\t

### Processed data
Processed data from scripts are provided in Zenodo, https://doi.org/10.5281/zenodo.22740567
